# Updated-Distance-Calculator
# Description
This Python program calculates the distance between two points on a 2D plane. It uses the Euclidean distance formula and the math library's sqrt() and pow () functions.
# How to run the program
1. Make sure Python is installed on your computer.
2. Open the python program.
3. Run the program.
4. Enter the values for x1, x2, y1, and y2.
5. The program will calculate the distance between the two points.
6. The program will display the distance between the two points.
# Input Needed
The program needs four inputs:
1. x1
- #x-coordinate of the first point
2. y1
- #y-coordinate of the first point
3. x2
- #x-coordinate of the second point
4. y2
- #y-coordinate of the second point
# Sample Output
- = Distance Between 2 Points Calculator =
- Enter x1: 1
- Enter y1: 2
- Enter x2: 4
- Enter y2: 6
- The distance between the 2 points is: 5.0
